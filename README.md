# Finance Analytics & AI Insights

## Overview
A portfolio project demonstrating how finance knowledge, data analytics and AI-oriented workflows can be combined to turn financial data into actionable business insights.

The project uses a synthetic dataset representing monthly departmental budgets, actual spending and revenue.

## Business question
How can a finance team identify budget pressure, understand departmental performance and prioritize areas for review?

## What I built
- Created a structured finance dataset covering 12 months and 5 departments.
- Calculated budget variance, variance percentage and profit after spend.
- Built a repeatable Python analysis workflow.
- Summarized departmental performance to support management review.
- Designed an AI-assisted insight workflow concept for explaining financial trends while keeping human review in the loop.

## Key metrics
- Budget
- Actual spend
- Budget variance
- Variance %
- Revenue
- Profit after spend

## Why it matters
The workflow demonstrates how repetitive finance analysis can be standardized and made easier to review. Instead of manually calculating the same metrics each month, the analysis can be rerun against updated data.

## Validation
I validated the workflow by:
1. Checking calculated variance values against the underlying budget and actual-spend figures.
2. Testing the analysis across multiple departments and months.
3. Reviewing whether the generated summaries identified the same areas of overspend visible in the raw data.
4. Keeping human review in the process for financial interpretation and decision-making.

## Tech stack
- Python
- Pandas
- CSV
- AI-assisted analysis/prompt design

## Important note
The dataset is synthetic and contains no confidential or personally identifiable information.
